# CryptoScope-AI

گزارشگر خودکار بازار رمزارز با تمرکز بر داده‌های آنچین، فاندامنتال، نقدینگی، جریان ETF و خبرهای مهم. خروجی به زبان فارسی در تلگرام ارسال می‌شود و داشبورد Streamlit نیز دارد.

## چه چیزهایی بررسی می‌شود؟

- ارزش کل بازار، حجم بازار، دامیننس بیت‌کوین و تغییرات BTC/ETH/SOL
- عرضه استیبل‌کوین‌ها و TVL دیفای به‌عنوان نشانه‌هایی از وضعیت نقدینگی اکوسیستم
- جریان خالص روزانه و هفتگی ETFهای BTC، ETH و SOL (در صورت تنظیم کلید سرویس)
- تعداد تراکنش‌ها و هش‌ریت شبکه بیت‌کوین
- شاخص ترس و طمع
- خبرهای ۴۸ ساعت اخیر در حوزه ژئوپلیتیک، اقتصاد کلان، انرژی، کریپتو و مقررات

**نکته مهم:** RSI، MACD و سیگنال‌های تکنیکال مبنای تحلیل نیستند. افزایش تراکنش یا هش‌ریت به‌تنهایی به معنی خرید نیست؛ عرضه استیبل‌کوین هم معادل ورود قطعی پول به صرافی‌ها نیست. گزارش این تفاوت‌ها را توضیح می‌دهد.

## راه‌اندازی تلگرام

در مخزن GitHub به مسیر **Settings → Secrets and variables → Actions → New repository secret** برو و این Secrets را اضافه کن:

| نام Secret | توضیح |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات از BotFather |
| `TELEGRAM_CHAT_ID` | شناسه چت یا کانال مقصد |
| `CRYPTOETF_API_KEY` | کلید سرویس جریان ETF؛ اختیاری |

برای ارسال به کانال، ربات باید در کانال دسترسی ارسال پیام داشته باشد. اگر کلید ETF تنظیم نشود، گزارش همچنان اجرا می‌شود و بخش ETF را «داده موجود نیست» نشان می‌دهد؛ مقدار ساختگی جایگزین نمی‌شود.

## اجرا

از تب **Actions**، ورک‌فلو **CryptoScope Daily** را باز کن و **Run workflow** را بزن. گزارش طبق زمان‌بندی UTC تعریف‌شده نیز خودکار اجرا می‌شود.

اجرای محلی:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python bot.py
```

برای داشبورد:

```bash
streamlit run app.py
```

## منابع داده

- CoinGecko: اطلاعات کلی بازار و قیمت دارایی‌ها
- DefiLlama: عرضه استیبل‌کوین‌ها و TVL
- Blockchain.com Charts: آمار تراکنش و هش‌ریت بیت‌کوین
- Alternative.me: شاخص ترس و طمع
- GDELT: خبرهای ۴۸ ساعت اخیر
- CryptoETF.today: جریان ETF، فقط در صورت ارائه کلید معتبر

## محدودیت و تفسیر

- هر منبع ممکن است با تأخیر، محدودیت نرخ یا قطعی مواجه شود؛ خطاها ثبت می‌شوند.
- امتیاز جهت بازار فقط از شاخص‌های واقعاً دریافت‌شده محاسبه می‌شود.
- سطح اطمینان به تعداد شاخص‌های معتبر وابسته است؛ داده ناقص باعث اعلام اطمینان بالا نمی‌شود.
- افق ۳ تا ۷ روز فقط وقتی نمایش داده می‌شود که چند شاخص مستقل هم‌جهت باشند؛ این سناریو تضمین نیست.
- تشخیص اهمیت خبر بر اساس کلیدواژه‌های عنوان است و جایگزین بررسی انسانی متن خبر نیست.
- این ابزار توصیه مالی یا تضمین پیش‌بینی نیست.

## امنیت

توکن تلگرام و کلیدهای API را داخل کد یا فایل‌های مخزن قرار نده؛ فقط از GitHub Secrets یا متغیرهای محیطی استفاده کن.
